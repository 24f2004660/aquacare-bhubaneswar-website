# AquaCare Bhubaneswar — Website

Official website for **AquaCare Bhubaneswar**, a water purifier service centre offering RO installation, repair, maintenance and filter replacement services in Bhubaneswar, Odisha.

**Live Website:** https://aquacarebhubaneswar.in/

## Overview

This project is a business website developed for AquaCare Bhubaneswar to establish its online presence and provide customers with easy access to service information and contact options.

The website presents the service centre's offerings through a responsive interface designed for desktop, tablet and mobile devices.

## Features

- Responsive and mobile-friendly interface
- RO installation and repair service information
- Filter replacement and maintenance services
- Service coverage information
- Customer enquiry and contact options
- WhatsApp integration
- Frequently asked questions
- Search engine optimization fundamentals

## Local Development

### Prerequisites

- Git
- Visual Studio Code or another code editor
- A modern web browser

### Installation

Clone the repository:

```bash
git clone https://github.com/24f2004660/aquacare-bhubaneswar-website.git
```

Navigate to the project directory:

```bash
cd aquacare-bhubaneswar-website
```

Open the project in Visual Studio Code:

```bash
code .
```

Open `index.html` in a browser to view the website. You can also use the Live Server extension for local development.

## Version Control

Git is used to track source code changes and maintain the project's development history.

```bash
git add .
git commit -m "Describe your changes"
git push origin main
```

## Deployment

The website is hosted on Netlify and connected to the GitHub repository for continuous deployment.

Changes pushed to the configured production branch automatically trigger a new deployment.

### Deployment Workflow

```text
Local Development
       |

   Git Commit

   GitHub Push
       |
       v

       |
       v
  Live Website
```
